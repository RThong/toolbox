# card-photo-to-scan

证件正反面手机照片 → 实际尺寸的 A4 扫描件 PDF(ID-1 卡片:在留卡 / 身份证 / マイナンバー / 驾照等,85.6 × 54 mm)。

依赖:**macOS**(用系统自带的 Vision 框架找卡片)+ `swift` + Bun。依赖装在上级 `toolbox/` 根目录(首次在那里 `bun install`)。

## 用法

```bash
bun scan.ts 正面.jpg 背面.jpg 扫描件.pdf
```

打印选「实际大小 / 100%」,不要「适合页面」。

## 原理

1. `detect.swift`:macOS Vision 矩形检测粗定位四角 —— 抗杂乱背景、光照不匀,但角点会偏(实测最多约 75px)
2. `scan.ts` 精修:在每条粗边附近的窄带里找最强的「暗→亮」台阶,拟合四条直线求交点
3. 透视拉正(600dpi)→ lanczos 缩到 300dpi → 圆角外涂白、加浅灰边 → JPEG 质量 85
4. 两张卡按 85.6 × 54 mm 嵌进 A4 页(pdf-lib),整页白纸不存图,一份约 250~310KB

## 前提

卡面要比紧贴它的背景亮(浅色卡放深色 / 中间色桌面)。白卡放白桌面会找不准。
找到的四边形长宽比偏离 ID-1(1.59)超过 8% 时会打印 ⚠,那时先看输出。
